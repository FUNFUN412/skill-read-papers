# 三栏 LaTeX 模板

这是可直接复制的 XeLaTeX 起点，示例文本与图均为原创。先将整个目录复制到论文项目，再替换 `main.tex`、`notes.tex` 和 `tutorial.tex` 中的示例；不要在 Skill 安装目录内存放实际论文。

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

需要 TeX Live/MacTeX 中的 XeLaTeX、latexmk、ctex、Fandol、TeX Gyre、TikZ、zref 和常用表格/数学宏包。坐标取自上一遍编译，通常需要两到三遍；使用 latexmk 等待其收敛。模板不要求 shell escape。

## 正文与标注

- `\Pair{P001}{英文}{中文}`：段首对齐的一对段落，第三格始终为空。`P001` 是稳定源块编号，勿随分页改变。
- `\EquationRow{E001}{1}{公式}`：独立公式只出现一次，跨英文和中文栏。宽公式应合理换行，不要无限缩小。
- `\ImageRow{F001}{图片路径}{图注}`：图片只出现一次，跨前两栏。
- `\NativeHL{N001}{对应文字}`、`\NativeMathHL{N001}{行内数学}`：原生高光；英中使用同一标注编号。在中文对应位置之后放 `\SourceAnchor{N001}`，同一标注只放一个源锚点。
- `\RegisterQA{N001}{问题}{答案}`：在 `notes.tex` 注册右栏问答。问题深蓝，答案深红。
- `\RegisterAnswer{N001}{答案}`：只显示解答。
- `\RegisterTutorialPointer{N001}{detail-target}{详见解释页}`：内容已在详细页解释时使用简短链接，避免重复答案。

ID 使用字母、数字和连字符；将 PDF 原始批注 ID 映射成安全 ID 后再写入 TeX。所有用户内容须经过正常 TeX 转义，不能将原始备注当作代码输入。

右栏是独立覆盖层，答案长度不影响正文行高。无法完整放下的备注会进入后续正文页右栏；到正文结束仍未放下的内容自动写入可分页的“详细解释页”。对应高光始终可点击跳转，有空间时另给出右栏提示。提示与问答使用同一空间分配器，防止相互遮挡。完整答案不截断，不丢弃。若源锚点持续未解析，编译会警告，应修复后交付。

## 详细解释页

在 `longtable` **外部**调用：

```tex
\ReaderDetailedPage{detail-target}{解释标题}{\input{tutorial.tex}}
```

该页所有文字深红，页眉“详细解释页”，有页眉横线，无显示页码，PDF 页面标签为空。正文逻辑页码在插页后恢复。内容超过一页会正常分页；要求“一整页”时，应在成品中检查确实只占一页。需要多栏教学内容时，可在 `tutorial.tex` 使用 minipage；过长内容应改为可分页段落。

结束表格、插页、重新开始表格都直接写在正文流中；不要在 `\input` 文件内部开始表格，然后在文件返回后立即使用 `\multicolumn` 共享行。表格单行不跨页，过长源段落须拆成保持追溯关系的子块。

## 检查输出

编译会生成 `main.reader-pages.tsv`，区分物理页、正文页码和解释页；`main.reader-notes.tsv` 记录侧栏框、定位提示和补充解答的去向。正文行起点保存在 `.aux` 的 `row-*-en`、`row-*-zh` 标签，便于比较基线位置。

本示例应有四张物理页，PDF 标签依次为 `1`、空、`2`、空；N001 位于第一页右栏，N002 完整进入最后的解释页。附带 `pages.json` 可直接传给技能的 `scripts/audit_reader.py`；替换示例内容后，应按真实页码和标题更新此计划。正式交付仍需检查渲染图像、正文覆盖、英中对应、公式、字体、框线、跳转、溢出和页码；模板编译通过不能替代这些检查。
